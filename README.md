# P5 Projects

This is where I store some P5 projects including

### Catch
a small game where you catch a ball with a block and it tracks your score
### Tron
an attempt at a recreation of the classic Tron lightcycles

### Circles
various colorful circles being constantly displayed on the screen randomly

### Stars
an attempt at the classic Windows Starfield screensaver with some controls to speed up or slow down the stars
